# 中華そば 麦の星 公式サイト

日本語・英語・簡体字中国語・繁体字中国語・韓国語の5言語に対応した公式サイトです。
ページ構成：トップ／メニュー／麦系のこだわり／店舗・アクセス／よくある質問／求人
GitHub Pages で無料公開しています（ファイルをアップロードすると、GitHub Actions が自動で公開します）。

## よくある更新作業

サイトの文章や価格は、すべて `src/data/` フォルダの中にまとまっています。

| やりたいこと | 編集するファイル |
|---|---|
| 価格・メニューを変える、期間限定を入れ替える | `src/data/menu.json` |
| 営業時間・定休日・住所・電話番号・求人URLを変える | `src/data/site.json` |
| 日本語の文章を変える | `src/data/i18n/ja.json` |
| 英語の文章を変える | `src/data/i18n/en.json` |
| 中国語（簡体字）の文章を変える | `src/data/i18n/zh-hans.json` |
| 中国語（繁体字）の文章を変える | `src/data/i18n/zh-hant.json` |
| 韓国語の文章を変える | `src/data/i18n/ko.json` |
| 写真を差し替える | `public/images/` に同じファイル名でアップロード |

- 価格は税込・カンマなしの数字で書きます（例：`"price": 1000`）。全言語のページに自動で反映されます。
- 定休日を変えるときは、`site.json` の `closed`（詳しい説明）と `closedShort`（短い表記）の両方を書き換えます。
- 屋号「中華そば 麦の星」と英語表記「MUGI no HOSHI」は、全言語で翻訳せずに使います。

写真の一覧は [`docs/photos.md`](docs/photos.md) にあります。
